# standup

Формирует отчёт о работе за вчерашний день на основе git-коммитов.

## Шаг 1 — Определи вчерашнюю дату

```bash
date -v-1d +%Y-%m-%d   # macOS / BSD
# или
date -d yesterday +%Y-%m-%d  # Linux / GNU
```

## Шаг 2 — Собери коммиты за вчера

```bash
YESTERDAY=$(date -v-1d +%Y-%m-%d)
git log \
  --after="${YESTERDAY} 00:00:00" \
  --before="${YESTERDAY} 23:59:59" \
  --format="%H%n%s%n%b%n---" \
  --all
```

Если репозиторий молодой и нет коммитов за вчера, попробуй последние N коммитов:

```bash
git log --oneline -10
```

## Шаг 3 — Сформируй отчёт

Используй полученные данные коммитов, чтобы написать структурированный стендап-отчёт на русском языке по следующему шаблону:

---

**Стендап — <ВЧЕРАШНЯЯ_ДАТА>**

**Что было сделано:**
- <Пункт 1 — понятное описание задачи/фичи на основе коммита>
- <Пункт 2 — ...>
- ...

**Детали:**
<Развёрнутое объяснение ключевых изменений: что именно реализовано, какие файлы/компоненты затронуты, почему именно такой подход.>

**Блокеры / вопросы:**
- Нет (или перечисли, если видно из коммит-сообщений)

**План на сегодня:**
- <Опционально: если есть незакрытые задачи или очевидные следующие шаги>

---

## Правила

- Если коммитов за вчера нет — честно сообщи об этом и покажи последние 5 коммитов с их датами.
- Не выдумывай детали — опирайся только на текст коммитов и diff-статистику (`git show --stat <hash>`).
- Пиши кратко и по делу — отчёт должен умещаться в 1–2 минуты устного пересказа.
- Технические термины (названия функций, файлов, компонентов) оставляй как есть, не переводи.
